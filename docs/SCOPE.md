# Project Scope

## Overview

ghoralantinu is a self-hosted data storage and access tool designed for small teams. It enables teams to:

- Store data securely on their own infrastructure
- Access data via networked services
- Manage team access and permissions
- Keep data within their control

## Target Users

- Small teams (5-50 people)
- Organizations requiring self-hosted solutions
- Teams with data privacy or compliance requirements

## Core Functionality

- Data storage backend
- Network service interface
- User/team management
- Data access and retrieval

## Non-Goals

- Large-scale enterprise deployment (initially)
- Cloud-only solutions
